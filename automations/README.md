# Marketing Automations

Ready-made scheduled jobs that run existing skills on autopilot. Set them up once, let them run weekly or daily.

## Available Automations

1. **Weekly Competitor Watch** - Monitor competitor content, keywords, and positioning
2. **AI Citation Monitor** - Track mentions in ChatGPT, Perplexity, and other AI platforms
3. **Weekly SEO Decay Check** - Find content losing traffic and rankings
4. **Pipeline Digest** - Weekly summary of leads, deals, and revenue signals
5. **Content Repurposing** - Turn existing content into new formats automatically

## How to Use

Each automation is a documented recipe. Pick one, follow the setup instructions, then schedule it to run on a cadence (daily, weekly, monthly).

Scheduling options:
- **Cron job** (Linux/Mac)
- **GitHub Actions** (any platform)
- **Zapier/Make** (no-code)
- **Agent scheduler** (if your agent supports it)

## Setup Requirements

Most automations need:
- API keys for the services they connect to
- Brand files from `start-here` skill (optional but recommended)
- A way to schedule and receive results (email, Slack, file)

See individual automation READMEs for specifics.

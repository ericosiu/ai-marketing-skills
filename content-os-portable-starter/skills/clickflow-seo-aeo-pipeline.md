# SEO/AEO Workflow Adapter — Portable Mirror

This workflow is vendor-neutral. A roadmap or optimization platform may be selected as an adapter during onboarding.

- Discover documented read and write capabilities; default to read-only.
- Treat keyword or visibility scores as triage inputs, not drafting permission.
- Run intent overlap, SERP sameness, information-gain, evidence, and canonical-owner gates.
- Create local briefs or drafts first. A remote roadmap write requires its own approval.
- A CMS draft write requires a separate approval and immediate readback.
- Publishing is a separately approved capability and is never inherited from draft permission.
- Record endpoint/capability, source window, freshness, receipt, and zero-mutation status for read-only runs.

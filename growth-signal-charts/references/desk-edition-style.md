# Desk Edition style guide

Use this specification to reproduce the Growth Signal identity without copying an example chart's claim or a private design board. User-approved house artwork can supplement it when supplied.

## Identity

Use a mostly white page with graphite text, a slim orange rail along the left edge, a small open-loop mark, a bold condensed headline and restrained technical labels. The result should feel like a useful desk reference. Keep the plot as the largest content area.

| Token | Default |
| --- | --- |
| Canvas | 1080 × 1350 pixels, portrait |
| Background | White `#FFFFFF` |
| Main text | Graphite `#19171B` |
| Rail and emphasis | Orange `#F05B24` |
| Secondary series | Violet `#6336C7` |
| Muted text | Dark gray with enough contrast for phone reading |
| Grid | Light neutral gray; use only where it aids comparison |

Use a darker orange for small text if the accent orange lacks contrast against white. Direct labels, position and shape must carry meaning as well as color.

## Reading order

1. Small series mark and publisher identity near the top.
2. A subject-specific headline with one finding, usually two lines or fewer.
3. A short definition of the population, measure or time period where needed.
4. One numerical chart with direct labels and visible units.
5. At most one short interpretation or essential qualification.
6. The chart's source at its bottom left, followed by a compact sample or observation-period note when material.

For multiple charts on one slide, give each its own citation. Do not shrink sources to fit decoration. Preserve clear margins between headline, plot, takeaway and source.

## Typography and density

Choose a licensed condensed display face for headlines, a readable sans serif for labels and body copy, and optional mono text for small technical labels. No fonts are bundled. Use available fonts with a similar hierarchy rather than assuming a platform-specific font path.

As starting values at 1080 pixels wide, try roughly 90–115 pixels for a headline, 32–42 for category labels and 27–30 for sources. Adjust to actual text length and font metrics. These are layout starting points, not fixed limits. Review the result at about 360 pixels wide and shorten copy before reducing essential type.

Use bars or dots for comparisons, a line for a real time series, a slope for two comparable time points, or an exact share plot for a part of a whole. Select the form from the evidence. A 100-cell grid should color exactly the stated integer percentage; use a different form when rounding would hide a material difference.

## Restraint

Keep illustrations small and relevant when used. Avoid dashboard panels, multiple stamps, decorative machinery, anime characters, full-page graph-paper backgrounds and oversized metadata tables. A new palette is an experiment until selected.

Keep the series identity consistent while varying chart forms. Never add a second slide to meet an arbitrary length. Label carousel pages as slides of the same carousel; standalone charts need no issue numbering.

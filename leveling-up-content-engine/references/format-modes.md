# Format Modes

Select one primary mode after resolving the source. Add secondary modules only when they serve distinct promises or portfolio jobs.

| Mode | Use when | Primary optimization |
|---|---|---|
| Portfolio Audit | Output is unspecified or the source is unproven | Diagnosis, inventory, first release wave |
| Long-form Optimizer | One promise sustains a full session | Package, opening, structure, proof order, pacing |
| Podcast Portfolio | A conversation contains distinct promises | Full episode plus differentiated derivatives |
| Mid-form Explainer | One idea needs 3–12 minutes | Independent hook, context, proof, payoff |
| Shorts Engine | One atom pays off in 15–90 seconds | First frame, compression, payoff, vertical composition |
| Micro and Teaser Engine | Curiosity and routing are the job | Hook testing and truthful destination routing |
| Tutorial and Product Demo | Viewer success means completing a task | Search intent, step order, screen clarity, completion |
| Case Study and Testimonial | Evidence supports a transformation | Problem, intervention, proof, caveats, result |
| Paid Creative | The goal is a conversion experiment | Audience, promise, proof, objection, mechanism, CTA |
| Distribution Only | The master only needs release operations | Metadata, captions, settings, schedule, readback |

Rank recommendations by strategic value, promise completeness, proof and rights confidence, differentiation, production effort, and learning value. Use a 1–100 priority score only for comparison, never as predicted performance.

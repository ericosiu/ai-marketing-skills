# Monday Reel Ideas

Views are the proxy. Leads are the point. This skill runs a weekly idea pipeline for a creator who sells to business operators: proven patterns in, 3 scripted ideas out, the creator picks a number and films. No guessing what to shoot.

## Principle

- Ideas come from evidence, not brainstorming. Every topic traces to a post that already broke out, either on the creator's own account or on a verified outside account.
- The bar never drops to fill the list. An outlier is 3.0x or more against its own median. If nothing clears the bar in a group, the delivery says so in one line.
- Copy the hook and the structure, never the topic alone. A breakout post carries a proven verbal hook, a proven visual hook, and a proven beat outline. The new script is written on that outline, beat for beat, with the creator's angle and proof numbers.
- Numbers are never invented. A script may use only numbers on a verified proof sheet. Any other business number becomes a bracketed slot the creator fills at filming.
- The delivery must be copyable at a glance. Screenshots and links sit inside each idea block, so the creator can open the source, see frame 0, and film.

## Research order

0. Score last week. Before new research, check the picks from earlier runs. For each pick that has since posted, report one line: the topic, its views, and its multiplier vs the current format median. A pick that has not posted yet gets one line saying so. This is the learning loop; never skip it when a pick exists.
1. The creator's outliers, last 30 days, all feed formats. Split the pull three ways and never mix the groups: feed reels (score on views vs the reel median), feed carousels (score on reach and saves vs the carousel median), and trial or repost copies (flagged and reported apart, never blended into feed medians). Report only posts at 3.0x or more, capped at the top 5 per group. Each outlier ships with its number, its multiplier, its link, and one line naming the creator's unique angle on it.
2. Signals and wider inspo, widest last. (a) The creator's saves from the last 7 days only; the full library is an archive, not a signal. A save needs no multiplier, but label it as a save. (b) Tracked creators in the same niche, scored against their own medians. (c) A wider scan of this week's breakouts from creators outside the tracked set. For any outside post, keep it only at 3.0x or more vs that creator's usual engagement, verified from their recent posts before any multiplier prints. Likes and comments are the proxy for other accounts; label them as engagement, never as views.

## Build 3 ideas

Each idea pairs one new trend or tool from the research with a marketing or business result.

- Anchor rule: at least 1 of the 3 ideas must extend the creator's own top outlier pattern or a format pattern proven on their own account. Outside inspo alone does not fill the set.
- Hooks (layer 2): name the source post's verbal hook (its first spoken or captioned line) and its visual hook (what frame 0 shows). The idea's hook copies that hook's shape with the creator's verdict or number in it. Never invent a new hook shape when a source post exists.
- Story hook pass: after the copied hook is set, run one pass from a storytelling hook library (families such as Transformation, Mistake, Turning Point, Behind-the-Scenes, Contrarian, Relatable, Client or Customer, Curiosity, Lesson, Decision). Name the one true detail the idea rests on. If a template in the fitting family takes that detail with no stretch, the hook line may be re-worded on the template, inside the copied shape. The template never replaces the copied shape and never adds a fact. If no family fits, the delivery line reads "none, copied shape only" and the copied hook ships as is. Template style bans bind only new hook lines; an anchor idea that copies the creator's own proven post keeps their opener and wording, because proven results outrank a style ban.
- Structure (layer 3): reduce the source post to a beat outline of 3 to 5 beats. Get the transcript where one is available; if not, reconstruct the outline from the caption, on-screen text, and a content summary, and label it "outline reconstructed". Write the script on that outline, beat for beat.
- Format tag: tag each idea with one format from the creator's active format library, written as the plain format name first with the library code after it.
- Script check: each script runs 70 to 110 spoken words (about 30 to 45 seconds). Count the words before delivery. The hook names a verdict or a number and works with the sound off. Skip side-income and get-rich angles. Buyer test: would a marketing manager at a $20M+ company save this and send it to their director?
- Dedupe: check each topic against the shoot list, the concept backlog, and ideas sent in earlier runs. Drop any topic already there or already posted in the last 30 days.

## Delivery shape

The full set ships as ONE organized document, never as a chat wall. The chat message carries only the document link, a one-line summary, and the reply line. Inside the document, in order:

- "Last picks, scored:" lines, when picks exist.
- "Your outliers, last 30 days (3x and up):" feed reels, then carousels, then trial copies under their own flagged line.
- The 3 ideas, numbered. Each idea block holds, in order: the format tag (plain name, then code); a format reference line with one plain line for what the format looks like, the format's reference video link, and the format's still image; the source reference line (whose post or save, its multiplier, its link); the source post's first frame as a real screenshot next to the source link (frame 0 for a reel, slide 1 for a carousel, the photo itself for a photo post), captured from the post itself and verified by eye, never AI-generated; "Hook it copies:"; "Story hook:" with the family and template, or "none, copied shape only"; "Outline:"; the hook; the full script; and the on-screen text.
- Reference link rule: every idea carries its reference link inside its own block, never only in the outliers block. An idea with no reference link does not ship.
- Last line: "Reply with a number. I build the record sheet for your pick."

## Rules

- No posting, no scheduling, no DMs. Ideas only.
- If a data source fails, deliver with what verified and name the gap in one line.
- Log the run and the creator's picks. The picks log is what step 0 reads next week.

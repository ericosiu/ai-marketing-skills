# Channel Profile Contract

Save one reusable profile per channel. User or project profiles override bundled fallbacks.

Required fields:

- Channel name and URL
- Profile version and review date
- Evidence sample
- Output root
- One-sentence core formula
- Palette, subject, typography, composition, motifs, brand feel, title-thumbnail relationship, and supported variations
- Must, prefer, and avoid rules
- Component budget and grouping exceptions
- Approved subject and style reference paths
- Approved co-design references, when the user asks to retain them
- Co-design calibration: promise patterns, title patterns, visual grammar, rejected tendencies, and what must repeat versus vary
- Evidence class for each durable lesson: direct preference, user correction, directional result, or measured performance
- Refresh gate

The refresh gate must say: refresh only when the profile is missing, the user explicitly requests it, or the user supplies replacement brand examples.

Keep observations separate from inference. Record YouTube A/B uncertainty and do not infer performance causality from raw views.

When the user explicitly asks the skill to remember a co-designed package, preserve the approved asset and calibration in the channel profile, increment the profile version and review date, and apply it before future ideation. Do not turn a channel-specific preference into a universal packaging rule.

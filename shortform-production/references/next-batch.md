# Actionable next batch

## What stays fixed

V5's readable intro/CTA backgrounds, caption geometry, typography, palette, natural framing, and stable explanation layout. This is how different episodes remain recognizable.

## What changes

The promise, proof, and storytelling sequence. Choose evidence, workflow, or operator story from the source. This is where creativity belongs.

## First production cycle

1. Select one unposted source clip with a complete argument, usable evidence, and a real payoff. Record the exact source timestamps. Avoid reposting a recent asset as a duplicate.
2. Write three opening cards for that same clip: problem, evidence, process. Each must fit one stable four-second treatment and pay off in the existing speech.
3. Render only the three opening previews. Review at phone size with sound. Choose one based on immediate understanding, curiosity, and honesty—not visual busyness.
4. Finish one master. Use a timed shot list to add one readable proof sequence or stepwise diagram where it helps. Return to the creator for the payoff. Run the existing eval and repair the highest-impact defects.
5. Deliver the master, SRT, cover/title, caption/CTA, review evidence, and a scheduling manifest. Publish only within the creator's named scope through the API; verify the result.
6. When results are available, record supported metrics at comparable ages. Decide one variable to change in the next clip. Keep the visual design stable while testing that change.

Deliverable for the first cycle: three opening previews, one finished short, one distribution package, and one explicit hypothesis. No automatic commitment to publish three similar versions.

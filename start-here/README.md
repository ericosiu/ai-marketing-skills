# Start Here

Write shared brand files from your site and reviews, then recommend which skill to run next.

## Quick Start

1. Install this skill
2. Tell your agent: "Run the start-here skill"
3. Provide your website URL
4. Optionally provide review URLs
5. Agent writes brand files to `brand/` directory
6. Agent recommends which skill to run next

## What It Creates

Brand files that all other skills reuse automatically:

- `brand/voice.md` - Brand voice, tone, key phrases
- `brand/offer.md` - Primary offer, pricing, CTA
- `brand/audience.md` - Target audience, ICP, pain points
- `brand/competitors.md` - Competitor list, positioning

## When to Use

- First time using these skills
- Setting up brand context
- Want a recommendation for which skill to run next
- Need to refresh brand voice or positioning

## Next Steps

After running this skill, the agent recommends which skill to run based on your goals:

- **Get found:** `seo-ops`
- **Website leads:** `conversion-ops` or `sales-pipeline`
- **Cold outbound:** `outbound-engine`
- **Research leads:** `lead-dossier`
- **Close deals:** `revenue-intelligence`
- **Create content:** `content-ops`
